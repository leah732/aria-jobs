What's real here, and what isn't

Jobs pulls real, currently-open IT/tech roles specifically from four public remote-job boards — RemoteOK, Remotive, Jobicy, and Arbeitnow — refreshed roughly every 30 minutes by a scheduled script. These are fully remote, global roles; verify PH eligibility on each listing itself.

Leads is still the original sample data from the prototype — client-finding wasn't part of the "make it live" request yet.

Matching now runs entirely offline (keyword-based), no external AI call — this keeps the whole thing free to run. See the README in this project if you want to add AI-powered matching back later (it requires your own paid API key).
